# dakoku-app

ワンタップで打刻できる勤怠アプリです。よく使う勤務時間をテンプレートにして、1か月分の予定をまとめて申請することもできます。

## 作った理由

勤怠アプリを実際に使ってみて、打刻のたびに時刻を入力するのが煩雑で手間だと感じました。予定を申請していないと打刻が完了せず、あとから時刻を選んで入れ直す必要もありました。そこで、ボタンを押した瞬間に打刻できて、予定の申請もラクにできるアプリを作ることにしました。

## 使う技術

- TypeScript
- Next.js（画面とサーバー）
- PostgreSQL（Neon）
- Vercel（公開先）
